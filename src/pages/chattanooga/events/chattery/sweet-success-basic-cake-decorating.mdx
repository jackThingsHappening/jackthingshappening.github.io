Marckita Wilkes teaches this beginner cake decorating class at The Chattery. Wilkes is a third generation baker and has run Marckita's Munchies full time since 2019. The class covers crumb coating, leveling, buttercream preparation, and piping bag techniques. Students also learn to create stars, shells, and rosettes. Each participant takes home a two layer freshly baked cake. Tickets are $71.21 and sales close 48 hours before class.

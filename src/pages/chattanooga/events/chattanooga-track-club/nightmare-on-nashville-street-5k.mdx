Nashville Street in Chattanooga gets a Halloween takeover for this 5K and Fun Run in late October. Costumes are standard. The race draws as many runners in monster suits as it does people going for a PR. A Fun Run option opens it up to kids and casual participants. The route along Nashville Street keeps things mostly flat. Check the CTC calendar for start time and registration.

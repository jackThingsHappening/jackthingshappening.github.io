Santa suits, elf hats, and reindeer antlers are standard gear for this one. Run Santa Run Chattanooga is a holiday costume race that draws competitive runners and first-timers in equal measure. It is part of the broader Run Santa Run series with events in cities across the country. The December date and festive atmosphere make it one of the more social races on the CTC calendar. Check the CTC website for distance, start location, and registration.

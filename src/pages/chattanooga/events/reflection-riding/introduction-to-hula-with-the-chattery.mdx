Learn the basics of hula in one easy hour. This friendly class with The Chattery covers simple steps and the stories behind the dance. The Chattery is a Chattanooga-based lifelong learning organization offering workshops across a range of topics. This outdoor class takes place at Reflection Riding Arboretum on Garden Road. No dance experience is required. The session runs about 60 minutes. Check the Chattery website for registration and pricing. Wear comfortable clothes and shoes you can move in. The class is held on the grounds of the nature center, with the garden and forest as the backdrop.

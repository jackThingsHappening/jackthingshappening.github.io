Three comedians each perform the same set once drunk, once high, and once sober. Timing and material hold up differently across all three states. This is part of the Lookout Comedy Festival, which runs multiple nights across Chattanooga venues. The format is a traveling show that has run at clubs and festivals nationally. Cherry St. Tavern hosts this performance. Check the Lookout Comedy Festival website for ticket details and the full festival lineup. The show runs late and is adult-rated.

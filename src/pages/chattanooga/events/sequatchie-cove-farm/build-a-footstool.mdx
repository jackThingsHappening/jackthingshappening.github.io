Spend the day with Tyler Rogers learning basic chair-making technique. You'll build a 3-legged Cumberland footstool using mostly hand tools and leave with it. No woodworking experience is needed - the design is learnable in a day. Sequatchie Cove Farm is in Sequatchie Valley, Tennessee, about an hour from Chattanooga. The farm hosts hands-on traditional craft workshops. All materials and tools are provided. Register through the Sequatchie Cove website. Check the site for cost and start time. The footstool uses a traditional Appalachian design with bent wood legs and a woven seat.

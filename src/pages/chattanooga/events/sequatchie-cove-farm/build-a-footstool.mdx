Spend the day with Tyler Rogers learning basic chair-making technique. You'll build a 3-legged Cumberland footstool using mostly hand tools and leave with it. No experience needed. Sequatchie Cove runs these workshops year-round — this is one of the better ones for learning a durable skill.
